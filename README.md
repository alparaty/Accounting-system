| الاختصار | الوظيفة |
| :---: | :--- |
| **`F6`** | إضافة سجل جديد (قيد، سند، فاتورة، صنف، مصروف، أصل) |

## 🏢 وحدات وشاشات البرطي المالي الشامل (18 وحدة وظيفية)

1. **⚙️ تهيئة النظام:** إعداد الفترات المحاسبية، أسعار صرف العملات (ريال، دولار، يورو، سعودي)، الفروع، والحسابات الوسيطة.
2. **🔒 المستخدمون والصلاحيات:** إدارة مستخدمي النظام ومجموعات الصلاحيات والرقابة الداخلية.
3. **🌳 الدليل المحاسبي (COA):** شجرة الحسابات المالية خماسية الرتب، التفريق الصارم بين الحسابات الرئيسية والفرعية، ودعم طرق الإضافة الثلاث واستيراد وتصدير إكسل.
4. **⚖️ الأرصدة الافتتاحية:** احتساب رأس المال تلقائياً من معادلة $\text{الأصول} - \text{الخصوم}$ وترحيل رصيد البداية للأستاذ العام.
5. **📓 القيود اليومية العامة:** فحص صارم لتوازن المدين والدائن مع دعم الأطراف المتعددة والبحث والتنقل.
6. **💵 الصناديق والبنوك (نقداً):** سندات الصرف والقبض النقدية وحساب الصندوق الدائن والمدين تلقائياً وتعدد العملات.
7. **🏦 الشيكات والبنك الوسيط:** دعم طرق الترحيل الأربع وحساب البنك الوسيط `112109` وتواريخ الاستحقاق.
8. **📑 التحصيل اليدوي للشيكات:** استعراض الشيكات المستحقة وإقفال حساب البنك الوسيط ومعالجة الارتداد.
9. **💸 المصروفات والنثريات المتكامل:** التصنيفات الهرمية، المصروفات الفورية والآجلة، سداد الدفعات، القوالب المتكررة، والربط بقائمة الدخل.
10. **🏢 الأصول الثابتة وإهلاكها:** كروت الأصول، احتساب الإهلاك بالقسط الثابت شهرياً وسنوياً، القيود الآلية، واستبعاد وبيع الأصول.
11. **👥 المرتبات والأجور (HR):** مسيرات الرواتب (المطولة والمختصرة)، خصم الغياب كإيراد للشركة (`ح/ 410301`)، وتصفية السلف والعهد.
12. **📊 الهيكل الإداري (إكسل):** جدول إكسل تفاعلي متكامل لإدارات وأقسام الشركة، كشف الموظفين، ودليل الفروع مع التصدير والاستيراد.
13. **🛒 المشتريات والاعتمادات المستندية:** فواتير المشتريات، الخصم المكتسب (`ح/ 510201`)، وحاسبة تكاليف الاستيراد والاعتمادات (CF) وتوزيع المصاريف الجمركية والشحن.
14. **🏷️ المبيعات والعملاء (إكسل):** جدول إكسل تفاعلي بأربع أوراق عمل (فواتير المبيعات، كشف العملاء، عمولات المندوبين ومردوداتها، وهوامش أرباح الأصناف) مع شريط دالات `fx` وتصدير فوري.
15. **🖥️ نقطة البيع السريعة (POS الكاشير):** إدارة الورديات ودرج النقدية، البيع بالباركود أو اللمس، متعدد طرق الدفع، والخصم الفوري من المخزن وطباعة الإيصالات.
16. **📦 المخازن والمستودعات:** كروت الأصناف، التحويل المخزني بين الفروع، وتسوية فروقات الجرد (المسموح وغير المسموح)، وصرف المكافآت العينية.
17. **🛡️ المراجعة والترحيل:** دورة الرقابة الثلاثية (إدخال ➔ مراجعة ➔ ترحيل نهائي) مع خيارات الترحيل الفردي والجماعي وفك الترحيل المشروط.
18. **📈 التقارير الختامية:** ميزان المراجعة بالأرصدة والمجاميع، الميزانية العمومية، وقائمة الأرباح والخسائر مع الطباعة المنسقة (`Shift+F8`).
